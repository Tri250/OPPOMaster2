# 更新日志

本文档记录 OPPOMaster2 - 大师影像参数库 的所有版本更新历史。

## v2.2.0 (2026-07-01)

### ✨ 新增功能

- **Android 16 (API 36) 全面适配** - compileSdk/targetSdk 升级至 36，适配所有行为变更
- **预测性返回动画** - 启用 `enableOnBackInvokedCallback`，支持系统级返回手势预测动画
- **Photo Picker 迁移** - 全面替换 `GetContent()` 为 `PickVisualMedia`，符合 Android 16 最佳实践
- **TrailSnap 影像管理** - 全新影像管理模块，支持相册、时间线、人物、地点、收藏、回收站等
- **SmartOptimize 智能优化** - 重新设计智能优化引擎和交互组件
- **StyleLUTGenerator 风格 LUT 生成** - 支持从图片生成 3D LUT 色彩查找表

### 🎨 优化改进

- **云存储连接验证** - 从空实现升级为真实 HTTP 请求验证（WebDAV PROPFIND、Drive API 校验）
- **直方图真实计算** - 参数调节页直方图从模拟数据替换为基于真实 Bitmap 的确定性 EV 计算
- **悬浮窗 Android 14+ 兼容** - 使用 `ServiceCompat.startForeground` 替代 `startForeground`，修复 targetSdk 36 崩溃
- **Google Play FGS 合规** - 添加 `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` 属性声明
- **RenderRequest 线程安全** - ID 生成改用 `AtomicLong`，避免并发问题
- **CI/CD 流程增强** - Release 工作流添加 Android SDK 配置、友盟密钥注入、官方仓库兜底

### 🐛 问题修复

- 修复 Android 14+ 悬浮窗启动时 `ForegroundServiceTypeException` 崩溃
- 修复云存储提供商验证显示"连接成功"但实际未校验的问题
- 修复参数调节直方图显示虚假随机数据的问题
- 修复 TFLite 误导性声明，更正为"启发式 AI 分析"
- 修复 AI 微调功能缺少图片上传、实时预览、导出的问题
- 修复预设详情卡主题颜色不统一的问题
- 修复底部导航栏不固定的问题
- 修复首页小卡片封面不显示的问题
- 修复关于页面版本更新功能异常的问题
