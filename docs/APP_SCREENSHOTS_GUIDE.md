# 应用截图指南

本文档提供应用商店上架所需截图的详细规格和要求。

---

## 截图规格要求

### Google Play 商店要求

| 项目 | 要求 |
|------|------|
| 格式 | PNG 或 JPEG |
| 最少数量 | 2张 |
| 最多数量 | 8张 |
| 最小尺寸 | 320px |
| 最大尺寸 | 3840px |
| 宽高比 | 建议使用设备实际屏幕比例（如 9:16、9:19.5） |
| 色彩空间 | sRGB |
| 文件大小 | 每张不超过 8MB |

### 推荐截图尺寸

| 设备类型 | 尺寸 | 宽高比 |
|---------|------|--------|
| 手机（标准） | 1080 x 1920 px | 9:16 |
| 手机（全面屏） | 1080 x 2160 px | 9:18 |
| 手机（长屏） | 1080 x 2340 px | 9:19.5 |
| 平板（7寸） | 1200 x 1920 px | 10:16 |
| 平板（10寸） | 1600 x 2560 px | 10:16 |

## 需要截图的页面列表

### 必需截图（核心功能展示）

| 序号 | 页面名称 | 展示内容 | 优先级 |
|------|---------|---------|--------|
| 1 | 首页 | 预设卡片网格、功能入口、Tab切换 | 高 |
| 2 | 预设详情页 | 参数展示、效果对比、应用按钮 | 高 |
| 3 | AI场景识别 | 场景分析结果、智能推荐预设 | 高 |
| 4 | AI微调界面 | 参数调节界面、实时预览效果 | 高 |
| 5 | 哈苏色彩科学 | HNCS色彩展示、大师风格预设 | 中 |
| 6 | 智能优化 | 优化前后对比、一键优化效果 | 中 |
| 7 | 水印编辑器 | 水印样式选择、自定义编辑界面 | 中 |
| 8 | 设置页面 | 应用设置、主题切换、关于信息 | 低 |

### 推荐截图顺序

1. **首页截图** - 展示应用主界面和预设库
2. **预设详情** - 展示核心功能：参数展示和应用
3. **AI场景识别** - 展示AI智能功能
4. **AI微调界面** - 展示专业调色工具
5. **哈苏色彩科学** - 展示品牌特色功能
6. **智能优化** - 展示一键优化效果
7. **水印编辑器** - 展示附加功能
8. **设置页面** - 展示应用设置选项

## 截图内容要求

### 通用要求

1. **清晰度**：截图必须清晰，文字可读
2. **完整性**：完整展示界面，无遮挡
3. **真实性**：展示真实功能，不得虚假宣传
4. **一致性**：风格统一，色调协调
5. **无敏感信息**：不得包含个人隐私信息

### 内容建议

#### 首页截图
- 展示预设卡片网格
- 显示功能入口图标
- 突出应用名称和品牌
- 可展示深色/浅色两种模式

#### 预设详情截图
- 展示预设参数详情
- 显示效果对比（前后对比）
- 突出一键应用按钮
- 展示预设描述信息

#### AI场景识别截图
- 展示场景分析结果
- 显示识别的场景类型
- 突出智能推荐预设
- 可展示分析过程动画

#### AI微调截图
- 展示参数调节界面
- 显示实时预览效果
- 突出AI智能调节功能
- 展示调节前后对比

#### 哈苏色彩科学截图
- 展示HNCS色彩效果
- 显示大师风格预设
- 突出色彩还原效果
- 可展示样张对比

#### 智能优化截图
- 展示优化前后对比
- 显示优化参数调整
- 突出一键优化按钮
- 展示优化效果

#### 水印编辑器截图
- 展示水印样式选择
- 显示自定义编辑界面
- 突出水印预览效果
- 展示EXIF信息水印

## 注意事项

1. **定期更新**：应用版本更新时，检查截图是否需要更新
2. **节日特别版**：可考虑节日主题截图
3. **A/B测试**：可准备多套截图进行A/B测试
4. **本地化**：每个目标市场语言都应提供对应语言截图
5. **品牌一致性**：截图风格应与应用整体品牌保持一致
