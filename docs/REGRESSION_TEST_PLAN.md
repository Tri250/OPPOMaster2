## 二、必测功能链路（26 条）

### 2.1 核心链路（6 条，P0）

| # | 链路 | 测试步骤 | 预期结果 |
|---|------|---------|---------|
| 1 | AI 微调 | 首页 → AI微调 → 选择图片 → 自动调参 → 应用 | 参数真实更新，可导出图片 |
| 2 | 云端预设同步 | 设置 → 预设源管理 → 添加订阅 → 同步 | 预设从 CDN 拉取并显示 |
| 3 | 预设创建→应用 | 创建预设 → 填写参数 → 保存 → 在详情页加载 → 应用 | 参数完整保存并生效 |
| 4 | 相机实时预览 | 哈苏之眼 → 取景器 → 切换预设 → 观察滤镜效果 | 实时帧滤镜无延迟/崩溃 |
| 5 | 图片导入→导出 | AI微调 → 选择图片 → 调整参数 → 保存到相册 | 图片成功保存到系统相册 |
| 6 | 悬浮窗 | 任意页面 → 开启悬浮窗 → 切换预设 → 关闭 | 悬浮窗正常显示/交互/关闭 |

### 2.2 崩溃回归测试（12 条，P0）

| # | 原崩溃场景 | 测试方法 | 通过标准 |

| 7 | GPU 渲染 ANR | 连续快速切换预设 20 次 | 无 ANR，UI 不卡顿 |

| 10 | 反模式修复按钮 | 取景器触发反模式提示 → 点击修复 | 按钮实际执行修复操作 |

## 三、性能基准

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| 冷启动时间 | < 2.0s | `adb shell am start -W` 测 5 次取均值 |
| 内存占用（首页） | < 200MB | `adb shell dumpsys meminfo` |
| 内存占用（取景器） | < 350MB | 取景器运行 30s 后测量 |
| APK 体积 | < 30MB | `ls -lh app-release.apk` |
| 帧率（取景器） | ≥ 30fps | 开发者选项 GPU 呈现模式分析 |

## 四、自动化测试执行

```bash
# 运行所有单元测试
./gradlew test

# 运行崩溃回归测试
./gradlew test --tests "com.silas.omaster.CrashRegressionTest"

# 运行版本回归测试
./gradlew test --tests "com.silas.omaster.V193RegressionTest"

# 生成覆盖率报告
./gradlew test jacocoTestReport
```
