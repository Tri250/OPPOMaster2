## 引言

欢迎使用 OPPOMaster2 - 大师影像参数库（以下简称"本应用"或"我们"）。我们非常重视您的隐私保护，并致力于保护您的个人信息安全。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

在使用本应用之前，请您仔细阅读并理解本隐私政策的全部内容。如果您不同意本隐私政策的任何内容，请立即停止使用本应用。

## 2. 数据使用说明

### 2.1 数据使用目的

我们收集和使用数据的目的包括：

1. **提供核心功能**
   - 保存和应用预设参数
   - 同步您的偏好设置
   - 提供个性化推荐

2. **改善用户体验**
   - 分析应用使用情况
   - 优化应用性能
   - 修复已知问题

3. **安全保障**
   - 检测和防止欺诈行为
   - 保护应用安全

### 2.2 数据使用原则

- **最小必要原则**：仅收集实现功能所必需的最少数据
- **目的限制原则**：仅在声明目的范围内使用数据
- **透明原则**：向您明确说明数据使用方式
- **安全原则**：采取合理措施保护数据安全

## 3. 数据存储说明

### 3.1 存储位置

| 数据类型 | 存储位置 | 存储期限 |
|---------|---------|---------|
| 应用设置 | 本地设备 | 应用卸载前 |
| 自定义预设 | 本地设备 | 应用卸载前 |
| 收藏夹数据 | 本地设备 | 应用卸载前 |
| 水印模板 | 本地设备 | 应用卸载前 |
| 缓存数据 | 本地设备 | 可随时清除 |
| 使用统计 | 友盟+服务器 | 匿名化处理 |

### 3.2 数据安全措施

我们采取以下安全措施保护您的数据：

1. **数据加密**
   - 本地数据采用加密存储
   - 网络传输使用HTTPS加密

2. **访问控制**
   - 严格的内部访问权限控制
   - 定期安全审计

3. **安全存储**
   - 数据存储在安全的服务器环境
   - 定期备份和灾难恢复机制

### 3.3 数据传输

- 所有网络通信均使用HTTPS加密协议
- 不传输您的原始照片数据
- 仅传输必要的应用使用统计信息

## 4. 用户权利说明

### 4.1 您的权利

根据相关法律法规，您享有以下权利：

| 权利类型 | 说明 | 行使方式 |
|---------|------|---------|
| 知情权 | 了解我们收集和使用您个人信息的情况 | 阅读本隐私政策 |
| 访问权 | 访问您的个人信息 | 应用内设置查看 |
| 更正权 | 更正不准确的个人信息 | 应用内编辑修改 |
| 删除权 | 删除您的个人信息 | 应用内清除数据或卸载应用 |
| 撤回同意权 | 撤回您之前给予的同意 | 应用设置中关闭相关功能 |
| 数据可携带权 | 获取您的数据副本 | 应用内导出功能 |

### 4.2 如何行使您的权利

1. **查看数据**：在应用设置中查看已保存的数据
2. **清除数据**：在应用设置中清除缓存和数据
3. **导出数据**：使用应用内的导出功能
4. **删除账户**：卸载应用将删除所有本地数据
