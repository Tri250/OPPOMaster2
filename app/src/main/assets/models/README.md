# TensorFlow Lite 模型文件目录

此目录用于存放 TFLite 推理引擎所需的模型文件。

## 模型文件说明

### 1. scene_classifier.tflite
- **用途**: 场景分类模型
- **类型**: MobileNetV3 变体
- **大小**: 约 700KB (INT8 量化)
- **输入**: 224x224 RGB 图像
- **输出**: 36 个场景类型的概率分布
- **场景类型**: 风景、人像、夜景、美食、街拍、建筑、宠物、雪景等

### 2. quality_analyzer.tflite
- **用途**: 图像质量评估模型
- **类型**: NIMA 变体
- **大小**: 约 500KB
- **输入**: 224x224 RGB 图像
- **输出**: 5 维质量评分（亮度、对比度、噪点、清晰度、总体）

### 3. param_predictor.tflite
- **用途**: 参数预测模型
- **类型**: 全连接网络
- **大小**: 约 200KB
- **输入**: 41 维特征向量（36 维场景特征 + 5 维质量特征）
- **输出**: 18 个哈苏调校参数

## 模型获取方式

当前为模型加载框架，实际模型文件需要：

1. **自行训练**: 使用 TensorFlow/Keras 训练模型并转换为 TFLite 格式
2. **官方下载**: 从项目官方渠道获取预训练模型
3. **模拟推理**: 在没有模型文件时，系统会自动使用模拟推理模式

## 模型放置位置

将模型文件放置在此目录下：
```
/workspace/app/src/main/assets/models/
  ├── scene_classifier.tflite
  ├── quality_analyzer.tflite
  └ param_predictor.tflite
```

## 注意事项

- 模型文件会在应用启动时自动加载
- 支持从 assets 或文件系统加载
- 建议使用 INT8 量化模型以减小体积和提高性能
- 模型版本更新时需要同步更新版本号配置
