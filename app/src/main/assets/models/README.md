## 模型概述

OMaster 应用使用三个协同工作的 TensorFlow Lite 模型来实现智能场景识别和参数调优：

```
┌─────────────────────┐     ┌─────────────────────┐
│   输入图像 (RGB)     │────▶│  scene_classifier   │
└─────────────────────┘     │  (场景分类模型)      │
                             └──────────┬──────────┘
                                        │
                              36维场景概率向量
                                        │
                                        ▼
┌─────────────────────┐     ┌─────────────────────┐
│   输入图像 (RGB)     │────▶│  quality_analyzer   │
└─────────────────────┘     │  (质量分析模型)      │
                             └──────────┬──────────┘
                                        │
                              4维质量评分向量
                                        │
                                        ▼
                    ┌───────────────────────────────────┐
                    │        特征融合 (40维)            │
                    │  36维场景特征 + 4维质量特征        │
                    └───────────────┬───────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────────┐
                    │        param_predictor            │
                    │        (参数预测模型)              │
                    └───────────────┬───────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────────┐
                    │     18个哈苏调校参数输出           │
                    │  (曝光、对比度、饱和度、色调等)     │
                    └───────────────────────────────────┘
```

### quality_analyzer.tflite - 图像质量分析模型

#### 基本信息

| 属性 | 值 |
|------|-----|
| **模型架构** | NIMA (Neural Image Assessment) 变体 |
| **基础网络** | MobileNetV2 特征提取器 |
| **文件大小** | ~500KB (INT8 量化) |
| **量化类型** | INT8 (全整数量化) |
| **目标设备** | 移动端 CPU/GPU/NPU |

#### 输入规格

```
名称: input
类型: FLOAT32 (量化后为 INT8)
维度: [1, 224, 224, 3]
格式: RGB, 像素值归一化到 [0, 1]
```

#### 输出规格

```
名称: output
类型: FLOAT32
维度: [1, 4]
格式: 归一化评分 [0, 1]
```

#### 输出指标说明

| 索引 | 指标 | 范围 | 描述 |
|------|------|------|------|
| 0 | 亮度评分 | 0.0 - 1.0 | 图像整体亮度质量，0.5为最佳 |
| 1 | 对比度评分 | 0.0 - 1.0 | 图像对比度质量，越高越好 |
| 2 | 噪点评分 | 0.0 - 1.0 | 图像噪点水平，越高表示噪点越少 |
| 3 | 清晰度评分 | 0.0 - 1.0 | 图像清晰度/锐度，越高越清晰 |

#### 评分标准

- **亮度评分**:
  - 0.0 - 0.3: 过暗或过亮
  - 0.3 - 0.7: 亮度适中
  - 0.7 - 1.0: 理想亮度

- **对比度评分**:
  - 0.0 - 0.3: 对比度不足
  - 0.3 - 0.7: 对比度适中
  - 0.7 - 1.0: 对比度良好

- **噪点评分**:
  - 0.0 - 0.3: 噪点明显
  - 0.3 - 0.7: 噪点可控
  - 0.7 - 1.0: 噪点极低

- **清晰度评分**:
  - 0.0 - 0.3: 图像模糊
  - 0.3 - 0.7: 清晰度一般
  0.7 - 1.0: 图像清晰锐利

#### 训练数据集

- **基础数据集**: AVA (Aesthetic Visual Attributes) 数据集
- **微调数据集**: 自建质量评分数据集 (约 30,000 张标注图片)
- **标注方式**: 专家人工评分 + 自动质量指标计算

### param_predictor.tflite - 参数预测模型

#### 基本信息

| 属性 | 值 |
|------|-----|
| **模型架构** | 全连接神经网络 (MLP) |
| **网络结构** | 40 → 128 → 64 → 32 → 18 |
| **激活函数** | ReLU (隐藏层) + Sigmoid (输出层) |
| **文件大小** | ~200KB (INT8 量化) |
| **量化类型** | INT8 (全整数量化) |
| **目标设备** | 移动端 CPU |

#### 输入规格

```
名称: input
类型: FLOAT32 (量化后为 INT8)
维度: [1, 40]
格式: 特征向量拼接
```

#### 输入特征组成

| 维度范围 | 来源 | 描述 |
|---------|------|------|
| 0 - 35 | scene_classifier 输出 | 36维场景概率向量 |
| 36 - 39 | quality_analyzer 输出 | 4维质量评分向量 |

#### 输出规格

```
名称: output
类型: FLOAT32
维度: [1, 18]
格式: 归一化参数值 [0, 1]
```

#### 输出参数映射

| 索引 | 参数名称 | 范围 | 实际值映射 | 描述 |
|------|---------|------|-----------|------|
| 0 | exposure | 0.0 - 1.0 | -2.0EV ~ +2.0EV | 曝光补偿 |
| 1 | contrast | 0.0 - 1.0 | -100 ~ +100 | 对比度 |
| 2 | saturation | 0.0 - 1.0 | -100 ~ +100 | 饱和度 |
| 3 | highlights | 0.0 - 1.0 | -100 ~ +100 | 高光调整 |
| 4 | shadows | 0.0 - 1.0 | -100 ~ +100 | 阴影调整 |
| 5 | whites | 0.0 - 1.0 | -100 ~ +100 | 白色色阶 |
| 6 | blacks | 0.0 - 1.0 | -100 ~ +100 | 黑色色阶 |
| 7 | clarity | 0.0 - 1.0 | 0 ~ +100 | 清晰度 |
| 8 | vibrance | 0.0 - 1.0 | -100 ~ +100 | 自然饱和度 |
| 9 | warmth | 0.0 - 1.0 | -100 ~ +100 | 色温 |
| 10 | tint | 0.0 - 1.0 | -100 ~ +100 | 色调 |
| 11 | sharpness | 0.0 - 1.0 | 0 ~ +100 | 锐化 |
| 12 | noise_reduction | 0.0 - 1.0 | 0 ~ +100 | 降噪 |
| 13 | vignette | 0.0 - 1.0 | 0 ~ +100 | 暗角 |
| 14 | grain | 0.0 - 1.0 | 0 ~ +100 | 颗粒 |
| 15 | fade | 0.0 - 1.0 | 0 ~ +100 | 褪色 |
| 16 | split_tone_highlights | 0.0 - 1.0 | 0° ~ 360° | 分离色调高光 |
| 17 | split_tone_shadows | 0.0 - 1.0 | 0° ~ 360° | 分离色调阴影 |

#### 参数映射公式

```kotlin
// 曝光补偿: 0.0-1.0 → -2.0EV ~ +2.0EV
val exposure = (output[0] - 0.5f) * 4.0f

// 对比度/饱和度等: 0.0-1.0 → -100 ~ +100
val contrast = (output[1] - 0.5f) * 200.0f

// 清晰度/锐化等: 0.0-1.0 → 0 ~ +100
val clarity = output[7] * 100.0f
```

#### 训练数据集

- **训练数据**: 约 100,000 张图片 + 专家调校参数对
- **标注方式**: 专业摄影师调校参数标注
- **验证集**: 约 10,000 张独立验证图片

## 使用注意事项

### 模型加载

- 模型文件会在应用启动时自动加载
- 支持从 assets 或文件系统加载
- 加载失败时自动使用生产级启发式分析，保证功能完整可用

### 性能优化

- **推荐使用 INT8 量化模型**：减小体积、提高推理速度
- **GPU 加速**：支持 OpenGL ES 和 Vulkan 委托
- **NNAPI 加速**：Android 8.1+ 设备自动启用

### 内存管理

- 模型加载后常驻内存，避免重复加载
- 单个模型内存占用约 1-2MB
- 推理时临时内存约 5-10MB

### 线程安全

- TFLite Interpreter 实例非线程安全
- 应用使用单例模式管理模型实例
- 推理操作在后台线程执行

## 故障排查

### 模型加载失败

```
错误: Failed to load model: scene_classifier.tflite
解决: 检查文件是否存在于 assets/models/ 目录
```

### 推理结果异常

```
错误: Output shape mismatch
解决: 确认模型版本与应用代码匹配
```

### 内存不足

```
错误: OutOfMemoryError during inference
解决: 减小输入图像尺寸或使用更小的批处理大小
```
