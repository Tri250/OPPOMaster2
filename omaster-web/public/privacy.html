OMaster 隐私政策

最后更新日期：2026年6月7日

感谢您使用 OMaster 应用。我们高度重视您的隐私保护，本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

重要提示：OMaster 是一款摄影参数预设管理工具，我们遵循最小化数据收集原则，仅收集应用正常运行所必需的信息。

一、信息收集

1.1 我们收集的信息

  • 应用偏好设置：主题模式、语言设置、收藏的预设等用户偏好数据，存储在您的设备本地。
  • 使用统计数据：匿名化的应用使用统计，用于改进产品体验（可在设置中关闭）。
  • 预设数据：您创建或导入的摄影预设参数，存储在您的设备本地。

1.2 我们不收集的信息

  • 相机图像数据：本应用仅读取Camera2参数（ISO、快门速度等），不采集任何相机图像或视频数据。
  • 个人身份信息：我们不收集您的姓名、电话号码、电子邮件等个人身份信息。
  • 精确位置信息：我们不收集您的GPS精确位置信息。
  • 通讯录/短信：我们不访问您的通讯录或短信内容。

二、权限说明

2.1 应用使用的权限

  • INTERNET：用于从服务器获取预设数据更新。
  • ACCESS_NETWORK_STATE：用于检测网络连接状态。
  • READ_MEDIA_IMAGES：用于读取相册图片以添加水印（Android 13+）。
  • SYSTEM_ALERT_WINDOW：用于显示悬浮窗快捷操作面板。

2.2 相机权限说明

本应用使用 Camera2 API 读取相机参数（如ISO、快门速度、光圈值等），用于自动填入预设参数。我们不采集、存储或传输任何相机图像或视频数据。

三、数据存储与安全

3.1 本地存储

您的所有偏好设置和预设数据均存储在您的设备本地，使用 Android Keystore 和 AES-256-GCM 加密保护。

3.2 数据传输安全

所有网络通信均使用 HTTPS 加密传输，我们禁止所有明文HTTP连接。

3.3 数据保留

您的数据仅在您的设备上保留。卸载应用将删除所有本地数据。

四、第三方服务

4.1 ML Kit 文字识别

本应用使用 Google ML Kit 进行图片文字识别，用于从截图提取相机参数。该服务在设备本地运行，不上传图片到服务器。

4.2 云同步服务

如果您启用云同步功能，您的预设数据将加密后上传至我们的服务器。您可随时在设置中关闭此功能并删除云端数据。

五、您的权利

  • 访问权：您可以在应用设置中查看所有存储的数据。
  • 删除权：您可以在应用设置中删除所有本地数据。
  • 导出权：您可以导出所有预设数据到本地文件。
  • 撤回同意：您可以随时关闭数据收集相关设置。

六、儿童隐私保护

本应用不面向14岁以下儿童。我们不会故意收集儿童的个人信息。

七、隐私政策更新

我们可能会不时更新本隐私政策。重大变更将在应用内通知您。继续使用应用即表示您接受更新后的隐私政策。
